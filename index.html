Government Infrastructure
DTI Queue Management System
→

The Department of Trade and Industry's regional branch was processing walk-ins with paper slips and a whiteboard. I rebuilt that from scratch — real-time WebSocket ticket generation, role-based inventory tracking, and a live admin dashboard with full audit history. Deployed to production and used by actual government staff daily.

Outcome: Queue throughput increased, paper records eliminated. Now the branch's primary operational system.

Academic Platform
Polycon — Faculty Consultation System
→

Faculty-student consultations had no digital record — appointments lived in text messages, sessions undocumented. Polycon: full-stack platform with real-time scheduling, push notifications, per-session docs, and separate portals for students and faculty.

Outcome: Zero missed appointments since launch. Session documentation rate: near zero → 100%.

Voice AI System

Privacy-first voice AI built entirely in Python: no API calls, no cloud. NLP intent classification routes to a modular plugin system — system controls, file management, reminders. Extensible: new capabilities without touching core logic.

About Me
I build systems the way architects design buildings — failure modes first, elegance second.

Currently finishing my CS degree in the Philippines, with production deployments already in the field. I gravitate toward problems with real consequences — government systems people depend on, tools that run unattended, interfaces used by people who never asked for them.

Security mindset first: every input hostile, every permission a liability, every data store a target. Pursuing Google's Professional Cybersecurity cert alongside UX design — because understanding how systems fail and how people think are the two most useful things a developer can know.
